### 5. Improvement proposal (the one change): restore NET semantics to the marginal hit gate

- **File:** `src/fpl_claude/backtest/simulate.py`, `decide_transfers()`.
- **Bug mechanism:** the GW2 fix was implemented, but with the threshold
  quietly redefined. GW2 §5 specified `marginal < threshold * hits ⇒ reject`
  where `marginal = result.objective − free.objective` is **net of hit
  cost** — i.e. each −4 must clear +4.5 NET (gross +8.5). The code as
  shipped tests `marginal < (threshold − hit_cost) * hits` — net ≥ +0.5,
  gross ≥ +4.5 — an 8× weakening of the required margin. Proof it bites: the
  GW3 audit reads "kept: gross 6.74 >= 4.5/hit", i.e. net +2.74 — the same
  class the GW2 review ruled a policy FAIL at net +2.48. Worse, the original
  GW2 Wood→Ekitiké hit (gross +6.48) would ALSO pass the gate as coded —
  the implementation does not stop the very case that motivated it. Only
  the manager veto stopped GW3's hit; a policy gate that needs a human
  rescue is not a gate.
- **Fix (1 line + audit string + config comment):** in `decide_transfers()`
  change the rejection test to `marginal < threshold * result.hits`; make
  the audit quote the net number ("net +2.74 < 4.5/hit"); amend the
  `hit_ev_threshold` comment in both `config/rules/*.yaml` to "min expected
  gain NET of the hit cost, per hit, on the marginal (hit-only) legs" so
  memo, config and code finally agree.
- **Testable, no future data:** unit tests — synthetic projections where the
  extra transfer's marginal is net +2.74 (GW3's case) ⇒ free-only squad
  returned; net +5.0 ⇒ hit kept; two hits at net +9.5 total ⇒ rejected
  (per-hit test). Deterministic, deadline-time inputs only.
- **Why this and not the minutes/tiny-sample fix:** both are evidenced, but
  this one is a spec-vs-implementation divergence with a written policy on
  one side and code on the other — zero modelling judgment involved, and it
  is the chokepoint every future hit flows through. With early-season
  projections still noisy (Ballard, Ekitiké cases), a net margin of +0.5 is
  inside the noise floor; +4.5 net is the margin of safety the policy
  always claimed. The minutes-certainty fix (Ballard family, two scalps)
  is next in the queue if it recurs.
- **Applies from GW4 onward; GW1–3 are not rerun.**
